# B-Roll Catalog Skill

This OpenClaw skill provides AI assistant integration for the broll-organizer catalog.

## Installation

```bash
npx openclaw skills add aydrian/broll-organizer/skills/broll-catalog
```

## Usage

Once installed, OpenClaw agents can query your B-roll catalog using commands like:

- `search -q "QUERY"` — Find clips by keyword
- `location -l "LOCATION"` — Find clips by location
- `video -i ID` — Get specific video details
- `stats` — Get catalog statistics

See [SKILL.md](SKILL.md) for full documentation.
